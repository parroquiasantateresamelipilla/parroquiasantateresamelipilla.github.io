# Parroquia Santa Teresa de Jesús de los Andes · Melipilla

Sitio web parroquial publicado en https://parroquiasantateresamelipilla.github.io

- `index.html`: la página.
- `data.json`: todo el contenido (horarios, personal, sacramentos, avisos, redes). Se edita desde el botón **Administrar sitio** al pie de la página.
- `evangelio.json`: cita del Evangelio del día. Se actualiza sola cada madrugada (`.github/workflows/evangelio.yml`) desde eucaristiadiaria.cl.
- `logo.jpg`: logo parroquial.
